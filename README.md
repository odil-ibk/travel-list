# Travel List 🧳

A packing list app built with React while following a React course on Udemy. Add the things you need to pack, tick them off, and see your packing progress.

## Features

- Add items with a quantity
- Mark items as packed
- Delete items or clear the whole list
- Sort items by input order, description, or packed status
- Stats at the bottom show how much you've packed

## What I practiced

- Building and nesting components
- Passing data with props
- Managing state with `useState`
- Lifting state up
- Controlled form inputs
- Derived state (calculating stats from existing state)
- Conditional rendering
- Rendering lists with `map()`

## Tech stack

- React
- JavaScript (ES6+)
- CSS

## Run locally

```bash
git clone https://github.com/odil-ibk/travel-list.git
cd travel-list
npm install
npm start
```

If the project uses Vite, run `npm run dev` instead of `npm start`.
